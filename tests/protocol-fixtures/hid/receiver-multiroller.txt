# The Dialpad's 0x4610 MULTI_ROLLER over the Bolt receiver, slot 3, in
# keyvo's order: getFeature(0x4610), getCapabilities, getRollerCapabilities
# per roller, then setMode(roller, DIVERTED) for both.
#
# Source: synthetic until the owner's capture of slice 7 (#187) replaces it.
# Feature index 0x0d and version 1 are the measured feature walk
# (docs/research/hidpp-features-dump.txt, MX Creative Dialpad). The layouts
# are the static pass (docs/research/2026-10-28-dialpad-static-pass.md §1 to
# §3); the roller capabilities `28 00 1f 00` and `b4 00 1f 00` (40 and 180
# increments, no ratchet) are the third-party replies quoted there (§2,
# shensquared / Julusian PR #22). The setMode replies carry no data; the
# static pass accepts an empty one. Requests use keyvo's swid 0xe.
#
