# The Dialpad's 0x4610 MULTI_ROLLER capabilities over the Bolt receiver,
# slot 3, in keyvo's order: getCapabilities, then getRollerCapabilities per
# roller. The index 0x0d comes from the slot search
# (receiver-slot-probe.txt), which resolved it with getFeature(0x4610).
#
# Source: own, the owner's hardware check of slice 7 (#187, part 2,
# 2026-10-30, https://github.com/qubernetic/keyvo/issues/187#issuecomment-6517302440),
# block "wake, search, diverts", `keyvo --dump dial` at 8f56281, Dialpad
# firmware RBO 07.00.B0016 (ms 33728 to 33796). The replies are the bytes
# the static pass quotes (docs/research/2026-10-28-dialpad-static-pass.md
# §2): roller 0 40 increments, roller 1 180, no ratchet. Requests use
# keyvo's swid 0xe.
#

< 11 03 0d 0e 02 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00

< 11 03 0d 1e 28 00 1f 00 00 00 00 00 00 00 00 00 00 00 00 00
