# Source: the owner's hardware check of slice 7 (#187, part 1, 2026-10-29,
# https://github.com/qubernetic/keyvo/issues/187#issuecomment-6504351636).

# run's raw `keyvo probe --dump` log (ms 0 to 396); the first replies of
# slots 1 and 2 are delayed to the slowest cold replies the owner measured

# getDeviceInfo reply is part 2's (2026-10-30,

# index 0x0d, so it has no real one. The software ids are
