# A getFwInfo reply reads `<type> <prefix:3 ascii> <number> <revision>
# <build:u16> <active> <transport pid:u16> ...`, version and build in BCD:
#   entity 0: type 1 bootloader  "BL2" 20.00 build 0017, inactive -> BL2 20.00.B0017
#   entity 1: type 0 application "U1"  66.00 build 0017, active   -> U1 66.00.B0017
#   entity 2: type 0x0b          "IM"  01.00 build 0017, inactive
#   entity 3: type 2 hardware    "HW " 00.00 build 0000, inactive

# (docs/research/hidpp-features.md).
