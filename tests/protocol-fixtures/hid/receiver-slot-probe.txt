# The Dialpad search over the Bolt receiver (spec §5.1, §5.8): keyvo asks
# each device index from 1 up for getFeature(0x4610) and stops at the first
# device whose getDeviceInfo model id carries the WPID BC00. Slot 1 is empty
# (the receiver's HID++ 1.0 error report, `8f`, code 0x08 unknown device),
# slot 2 holds a device that does not answer within [timing].slot_probe
# (asleep), slot 3 holds the Dialpad.
#
# Source: synthetic until the owner's capture of slice 7 (#187) replaces it.
# The error report is the layout of the public Unifying receiver

# keyvo's swid 0xe.
